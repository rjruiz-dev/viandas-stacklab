# Wireframes — Viandas StackLab

> Bocetos de baja fidelidad para los flujos principales de usuario.

## Estado

🔲 **Pendiente** — Se crearán durante la Etapa 1 (Esqueleto).

## Flujos a Diseñar

1. **Empleado — Configurar días de asistencia**: selector semanal (lunes a viernes, toggle oficina/remoto)
2. **Empleado — Ver menú semanal**: lista de días con plato principal, opción vegetariana, sin TACC
3. **Empleado — Confirmar vianda**: tarjeta por día, botón "Confirmar", feedback visual ✓
4. **Empleado — Modificar pedido**: cambiar selección o cancelar (hasta el deadline)
5. **Administrador — Dashboard consolidado**: tabla con empleados × días, conteo de viandas por tipo
6. **Administrador — Cargar menú semanal**: formulario simple para ingresar platos del lunes al viernes
7. **Deadline — Pantalla de bloqueo**: mensaje "El plazo de confirmación cerró" post-deadline
