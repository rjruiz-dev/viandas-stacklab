## Guía de Estilo (Propuesta)

| Elemento | Valor |
|----------|-------|
| **Paleta principal** | Por definir con identidad de StackLab |
| **Tipografía** | Inter (UI), system font stack como fallback |
| **Espaciado** | Sistema de 4px (4, 8, 12, 16, 24, 32, 48) |
| **Radio de bordes** | 8px (cards), 6px (botones), 4px (inputs) |
| **Sombras** | Sutiles, elevación máxima de 3 niveles |
